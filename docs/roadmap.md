# OpsOrigin 后续规划

> 记录能力演进方向与暂缓项。已落地能力的明细见各模块与提交记录。

## 1. 已落地能力概览

- CMDB 模型 / 实例 / 拓扑 / 采集策略。
- 监控中心插件与采集体系。
- ITSM 流程引擎、SLA/OLA、变更管理、服务目录、员工门户。
- AI 中心：数字员工、技能市场（评分 / 收藏 / 版本）、MCP 工具、提示词库、AI 工作空间、长期记忆。
- 知识库、报表中心、统一报表数据集。
- 多云平台接入（公有云 + 私有云 / 超融合）。

## 2. 暂缓方向（待底座稳固后开工）

以下方向已规划但暂缓，待 ITSM 与监控底座稳定后启动：

- **变更风险预测**（#154）：依赖 ITSM 变更 / 工单链路。
- **容量预测闭环**（#155）：依赖监控真实指标流 + 工单创建。
- **异常检测算子化**（#156）：依赖监控采集底座 + 巡检工具链。

## 3. 规划中

- AI 定义工作空间与报表中心的深度联动。
- 知识库自动沉淀策略的闭环。
- 更多私有云 / 超融合 provider 接入。
