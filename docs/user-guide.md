# OpsOrigin 用户手册

> 面向运维工程师与平台管理员的快速上手指南。功能细节以各模块内联帮助为准。

## 1. 快速上手

1. **系统设置**：配置租户、全局默认采集策略、通知渠道。
2. **资源纳管**：在 CMDB / 云纳管中接入主机、容器与云资源，按需开启 CMDB / 监控采集。
3. **采集与拓扑**：等待采集任务产出配置项与拓扑关系。
4. **监控与告警**：在监控中心查看指标、配置告警与通知。
5. **AI 自动化**：在数字员工中启用岗位模板 / 主动巡检，按需引入技能市场能力。

## 2. 模块导航

- **CMDB**：全局搜索 → 落地页 → 配置项 / 拓扑 / 机房机柜。
- **监控中心**：插件目录 / 采集任务 / 指标告警。
- **ITSM**：工单 / 流程设计 / 服务目录 / 变更日历。
- **AI 中心**：数字员工 / 技能市场 / MCP 工具 / 提示词库 / AI 工作空间。
- **知识库**：文章 / 收藏 / 关注 / AI 伴写。
- **报表中心**：我的看板 / 数据探索。

## 3. 核心工作流

纳管 → 采集 → CMDB 建模 → 监控告警 → ITSM 处置 → AI 自动闭环。
